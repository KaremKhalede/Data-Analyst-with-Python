# Data Analyst with Python Career Track

This repository contains my practical notebooks, notes, and data visualization projects as I progress through the DataCamp career track.

## Contents
* **01_Matplotlib**: Introduction to Data Visualization (Line plots, Scatter plots, Histograms, and advanced customizations).

* **02_Dictionaries_and_Pandas**: Introduction to Python Dictionaries (Key-Value pairs, manipulations, nested dicts) and Pandas DataFrames indexing (`loc` and `iloc`).

* `03_Logic_and_Control_Flow.ipynb`: Core logic, comparison/boolean operators, conditional statements, and data filtering.
